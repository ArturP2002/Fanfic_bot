# Известные технические ограничения FicBrain v1

## Ролики Instagram / TikTok

- Основное скачивание — через **yt-dlp**. Apify — запасной путь (у TikTok-scraper прямая ссылка на mp4 часто пустая без платного `shouldDownloadVideos`).
- Ссылки могут перестать открываться из‑за политики площадок без изменения кода.
- При ошибке скачивания бот просит прислать видеофайл — это ожидаемое поведение.
- Длинные ролики увеличивают стоимость Whisper/OCR/LLM и время ответа.

## Распознавание

- Whisper может ошибаться в именах собственных и сокращениях.
- OpenAI Vision OCR может ошибаться на мелком/размытом/стилизованном тексте на кадрах.
- LLM не должна выдумывать данные, но при очень шумном вводе возможны пропуски.
- Несколько произведений в одном ролике извлекаются эвристически/LLM — полнота не гарантируется на 100%.

## Прямые ссылки

- Надёжно поддерживаются: **AO3**, **Ficbook**, **FanFiction.net**.
- Вёрстка площадок может измениться — парсеры потребуют обновления.
- Часть страниц может быть недоступна без авторизации или из-за региональных ограничений.

## База и дубли

- Автослияние только при высокой уверенности; иначе бот спрашивает пользователя.
- Сомнительные новые записи помечаются `needs_review`.
- Полные тексты фанфиков не хранятся.

## Инфраструктура

- Очередь Redis: при падении worker задачи не обрабатываются, пока сервис не поднят снова.
- Временные медиа удаляются после обработки; повторный разбор того же файла требует новой загрузки.
